# Appliance Energy Consumption Website — T01(a)

## About
A 3-page static website (Home, Televisions, About Us) built for COS30045 Data Visualisation, exercise T01(a). Built with plain HTML, CSS and JavaScript.

## Pages
- `index.html` — Home
- `televisions.html` — Televisions
- `about.html` — About Us
- `css/style.css` — styling
- `js/main.js` — nav active-state highlighting, dynamic footer year
